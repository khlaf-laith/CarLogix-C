# Car Logix - Car Warehouse & Maintenance Management System

**Course:** Programming 1 (C Language)  
**Author:** Laith Khlaf  

## Overview
Car Logix is a console-based management system written in C using binary file handling (`fread`/`fwrite`), structures (`struct`), and singly linked lists. It manages vehicles, owners, spare parts inventory, and maintenance operations.

## How to Run in VS Code
1. Open the `CarLogix` folder in **VS Code**.
2. Make sure you have the **C/C++ Extension** by Microsoft and a C compiler (**GCC / MinGW**) installed.
3. Open `main.c` and press `Ctrl + Alt + N` (if using Code Runner) or press `F5` / run in terminal:
   ```bash
   gcc main.c -o car_logix
   ./car_logix
   ```
